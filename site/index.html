Utilisation

Là où le texte est déjà.

Pas de copier-coller vers un autre outil : la correction se fait sur place, dans le champ en cours d'écriture.

Raccourci clavier

⌘ droit + / par défaut, ou la combinaison de son choix. Corrige la sélection, ou tout le champ s'il n'y en a pas, puis recolle le résultat.

Clic droit

« Reformule : corriger et reformuler » et « Reformule : corriger seulement », dans le menu Services de la sélection. Sans toucher au presse-papiers.

Deux modes

Corriger et reformuler pour des tournures plus naturelles, ou corriger seulement pour changer le moins de mots possible. Le ton et la langue sont gardés.

Mise en forme

La structure ne passe jamais par le modèle.

Reformule découpe le texte en blocs et garde lui-même les paragraphes, les puces et l'imbrication. Le modèle ne reçoit que le texte de chaque bloc.

  • Gras
  • Italique
  • Liens
  • Code
  • Listes à puces
  • Listes numérotées
  • Listes imbriquées
  • URL et code protégés. Ils sont remplacés par des jetons que le modèle doit recopier tels quels.
  • Chaque bloc est vérifié. Si ses marqueurs ou ses jetons ont changé, il reste tel qu'il était.
  • Rien de risqué n'est touché. Un texte avec images ou tableaux n'est pas modifié du tout.

Réglages

Une fenêtre, tous les choix.

Modèle (Fable, Opus, Sonnet ou Haiku), effort, mode, raccourci et ouverture à la session. La fenêtre s'ouvre depuis la barre des menus, ou en rouvrant l'app quand l'encoche cache son icône.

Fonctionnement

Cinq étapes, quelques secondes.

Environ 3 à 4 secondes avec Opus en effort faible, une dizaine avec Fable.

  1. Copie

    Reformule envoie ⌘C. Si rien n'est sélectionné, il sélectionne tout le champ puis copie.

  2. Découpage

    Le contenu devient une liste de blocs ; les URL et le code sont remplacés par des jetons.

  3. Correction

    Claude Code reçoit les blocs et en renvoie autant, sans outils, serveurs MCP ni réglages personnels.

  4. Vérification

    Un bloc dont la mise en forme a changé est gardé tel quel.

  5. Collage

    Le HTML, le RTF et le texte brut sont reconstruits et collés, puis le presse-papiers d'origine est restauré.

Installation

Compilée sur sa propre machine.

  • macOS 26 sur Apple silicon
  • Claude Code installé et connecté
  • Les outils en ligne de commande Xcode (xcode-select --install)

Autoriser ensuite Reformule dans Réglages Système > Confidentialité et sécurité > Accessibilité, pour le raccourci clavier. L'app étant signée ad hoc, l'autorisation est à redonner après chaque compilation. Le clic droit s'en passe.

$ git clone https://github.com/mickadoua/reformule.git
$ cd reformule
$ ./build.sh install
$ open ~/Applications/Reformule.app

Confidentialité

Le texte part chez Anthropic par Claude Code, avec le compte connecté, et compte sur son abonnement ou sa facturation. Reformule n'a ni serveur ni télémétrie, et ne conserve aucune session.

Limites

  • Textes avec images, émojis en image ou tableaux : rien n'est modifié.
  • Le souligné, le barré et les couleurs sont perdus.
  • Les apps qui remplacent le menu contextuel, comme beaucoup d'apps Electron, n'affichent pas les Services : le raccourci y fonctionne.
