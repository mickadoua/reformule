Usage

Right where the text already is.

No copying to another tool and back: the correction happens in place, in the field you are typing in.

Keyboard shortcut

Right ⌘ + / by default, or any combination you like. Corrects the selection, or the whole field when nothing is selected, then pastes the result back.

Right-click

Two entries in the Services menu of any selection, to correct and rephrase or to correct only. The clipboard is never touched.

Two modes

Correct and rephrase for more natural wording, or correct only to change as few words as possible. Tone and language are always kept.

Formatting

The structure never goes through the model.

Reformule splits the text into blocks and keeps paragraphs, bullets and nesting itself. The model only receives the text of each block.

  • Bold
  • Italic
  • Links
  • Code
  • Bulleted lists
  • Numbered lists
  • Nested lists
  • URLs and code are protected. They are swapped for tokens the model has to copy back as is.
  • Every block is checked. If its markers or tokens changed, it stays as it was.
  • Nothing risky is touched. Text with images or tables is not modified at all.

Settings

One window, every choice.

Model (Fable, Opus, Sonnet or Haiku), effort, mode, shortcut and launch at login. The window opens from the menu bar, or by opening the app again when the notch hides its icon. The interface is in French for now.

How it works

Five steps, a few seconds.

About 3 to 4 seconds with Opus at low effort, around ten with Fable.

  1. Copy

    Reformule sends ⌘C. If nothing is selected, it selects the whole field and copies again.

  2. Split

    The content becomes a list of blocks; URLs and code are replaced by tokens.

  3. Correct

    Claude Code receives the blocks and returns as many, with no tools, MCP servers or personal settings.

  4. Check

    A block whose formatting changed is kept as it was.

  5. Paste

    HTML, RTF and plain text are rebuilt and pasted, then the original clipboard is restored.

Install

Built on your own Mac.

  • macOS 26 on Apple silicon
  • Claude Code installed and signed in
  • Xcode Command Line Tools (xcode-select --install)

Then allow Reformule in System Settings > Privacy & Security > Accessibility, for the keyboard shortcut. The app is signed ad hoc, so the permission has to be granted again after every build. The right-click menu works without it.

$ git clone https://github.com/mickadoua/reformule.git
$ cd reformule
$ ./build.sh install
$ open ~/Applications/Reformule.app

Privacy

Text goes to Anthropic through Claude Code, with the signed-in account, and counts against its subscription or billing. Reformule has no server and no telemetry, and keeps no session.

Limitations

  • Text with images, image emoji or tables: nothing is modified.
  • Underline, strikethrough and colors are lost.
  • Apps that replace the context menu, like many Electron apps, do not show Services: the shortcut works there.
